## 📌 Executive Summary
This repository contains the deliverables for the **Week 5 DevSecOps Practice Task**: **Backup & Recovery Drill** for the Audex platform. The goal of this drill is to establish a reliable, repeatable, and automated workflow for backing up critical system configurations and data packages, simulating a data corruption/loss scenario in a sandbox environment, and executing a successful restoration process with zero data loss.

---

## 🎯 Objectives & Scope
- **Backup Strategy:** Create an automated, timestamped backup archive of critical configuration files (`audex_config.json`).
- **Disaster Simulation:** Simulate a critical failure by intentionally removing the primary system configuration file in a controlled sandbox environment.
- **Recovery Execution:** Validate the integrity of backup packages and execute an automated restore operation to bring the system back to an operational state.
- **Runbook Documentation:** Provide structured step-by-step procedures in JSON format (`runbook.json`) for traceability and disaster response readiness.
